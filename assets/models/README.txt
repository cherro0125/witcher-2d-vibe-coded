Modele 3D dla Wiedźmin: Szkoła Dzika
=====================================

Gra używa proceduralnych modeli (kapsułki, sfery, torusy).
Aby użyć własnych modeli .glb/.gltf, umieść je tutaj:

  assets/models/player.glb     - Model gracza (Gerarda)
  assets/models/ghoul.glb      - Ghul
  assets/models/wolf.glb       - Wilkołak
  assets/models/leshen.glb     - Leszy
  assets/models/griffin.glb    - Gryf
  assets/models/tree_pine.glb  - Drzewo sosnowe
  assets/models/npc_villager.glb - Wieśniak

Darmowe zasoby 3D (CC0/publiczna domena):
  - Kenney.nl: https://kenney.nl/assets (CC0, świetna jakość!)
  - Quaternius: https://quaternius.com/packs/ultimatemonsters.html
  - Poly Pizza: https://poly.pizza (CC-BY, darmowe)
  - Kaykit: https://kaylousberg.itch.io/ (CC0, low-poly)
  - OpenGameArt: https://opengameart.org/art-search-advanced?field_art_type_tid=10

Format: Bevy obsługuje .glb i .gltf (z embedded textures preferowany .glb)
